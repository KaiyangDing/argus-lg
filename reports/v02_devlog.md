## Iteration 0 —— 基线（v0.1 引擎三份报告，三人评审组并行评审）

**系统性缺陷六类（三份共病，整改优先级序）**：
1. 引用错位不可审计（off-by-one 型多例）；
2. 手握弹药不用（lpz 区域塌方/渠道拆分/会员逆势/季度收窄轨迹、yh 五年亏损序列/门店腰斩
   1000→775→403/19 亿处置收益平滑利润/大股东七成质押、szss 扣非 -84.53%/吨价 4.4→3.6 万
   全部闲置）；
3. 时间锚错位与年份错配（2024 数据冒充 2025 当期）；
4. 口径混用（母公司/合并）与过期数据（京东持股已转让仍在列）；
5. 超证据断言与反向结论（yh「无重大诉讼」vs 年报勾选「√有重大诉讼」）；
6. 结构缺投资要点/独立风险章节，同组数字跨节重复三遍充数。

**评审金句存档**：lpz「骨架像研报、血肉是年报复述」；yh「这是一份带引用格式的年报摘抄，
不是尽调」；szss「把 FY2025 利润塌方写成了 FY2024 成绩单的三遍复读」。

**本轮动作（零成本，代码已落）**：
- 架构：researcher 单轮流水线 → 多轮 map-reduce agent（检索→备忘录消化→缺口自评 ≤3 轮，
  总证据无帽、单窗有界 ROUND_INTAKE=18/CORE_CAP=24）；merge 后复审补派一轮（≤2 任务）；
  write 三层化（投资要点/节三段式[事实表格→分析→风险]/跨方面关联/风险汇总/边界）；
  build_graph 增 write_chat 参数（写作层可 A/B qwen-plus）。
- 提示词全面专业化（argus_lg/prompts.py，内置尽调五维框架/检索策略手册/缺口自评清单/
  研报文体规范/口径纪律/时间锚）。
- 测试重写 34 枚全绿（多轮累积/补派恰一次/零证据零调用等编排全 Fake 锁定）。

## 收口结论（2026-08-18）

- **目标达成度**：报告从几百字事实罗列（基线评审「小儿科」原话成立）→ **6000~9000 字三层研报**
  （投资要点 / 各节【事实+表格】【分析】【风险】三段式 / 跨方面关联 / 分类风险 / 边界），
  金标覆盖 **13/18 历史最高**，防幻觉三闸全程未破（三家陷阱 0、越界 0）。多 agent 的理由随深度
  成立：researcher 3 分钟/方面（多轮检索-消化-自评）、上下文分区（每方面独立备忘录）、
  复审补派实际产出增量（线上占比缺口即补研解决）。
- **工程问题账**：10 类实际问题全部走完「现象→根因→机制对策→验证」闭环（黑洞请求 /
  json_schema 挂死 / 粘性拒调 / 节点级脆弱 / 章节重复 / 语义错配 / 硬编码年份 / 验证器切片偏差 /
  引用纪律 / 观测缺失）——每条都是可面试的一手素材。
- **天花板（数据点名）**：表列对齐错配=通用解析件（pypdf 线性化）固有限制，prompt/架构层无解；
  处方=结构化表格解析。**产品仓冻结 mineru-api 契约的决策由此获得最终实证。**
- **花费**：v0.2 全程 ≈**¥8.0**（授权 ¥10 内），其中约 ¥1.1 是四次失败跑的学费——每分学费
  都换到了一条工程问题账条目。
